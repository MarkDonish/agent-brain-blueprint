# Example App

## Purpose

Fictional sample project used only to demonstrate vault layout.

## 30-second entrypoint

1. Read `10_current_work/INDEX.md`.
2. Read the newest handoff under `20_handoffs/`.
3. Read the newest validation record under `40_validation/`.
4. Revalidate any live or production fact before acting.

## Recommended folders

- `10_current_work/` active tasks
- `20_handoffs/` session and agent handoffs
- `30_docs/` non-sensitive design notes
- `40_validation/` evidence before closeout
- `50_decisions/` durable governed decisions
- `60_summaries/` short session summaries
- `90_raw_sources/` source pointers only

## Boundary

This is fictional documentation. Replace it with source-backed project records.
Never store credentials, raw private conversations, databases, or customer data here.
