# Fictional Demo Vault

This directory is intentionally tiny and non-personal. It exists so readers can
see the intended shape without bootstrapping first.

For a full local vault, prefer:

```bash
python3 scripts/bootstrap.py --destination ../my-agent-brain
python3 scripts/doctor.py ../my-agent-brain
```

## Safety

This example contains no personal, customer, runtime, or production information.
Do not replace these files with real vault content inside the public repository.
